# Live Demo Guide

This document outlines a structured narrative for presenting the ShortlistIQ platform during a project review or stakeholder demonstration.

## 1. Environment Setup
Before starting the demo, ensure the environment is pristine and loaded with realistic data.
1. **Start Backend**: 
   ```bash
   cd backend
   source venv/bin/activate # (or venv\Scripts\activate on Windows)
   pip install -r requirements.txt
   python populate_demo.py  # Clears DB and seeds realistic mock data
   python run.py
   ```
2. **Start Frontend**:
   ```bash
   cd frontend
   npm install
   npm run dev
   ```

## 2. Demo Narrative: "The Complete Hiring Lifecycle"

### Phase 1: The Landing Page & Vision
- **Action**: Open `http://localhost:5173`.
- **Talking Points**: Highlight the premium SaaS design. Explain the core value proposition: moving beyond rigid keywords to semantic, AI-driven contextual matching.

### Phase 2: The Recruiter Experience
- **Action**: Log in as a Recruiter (use credentials generated by `populate_demo.py`, typically `recruiter@example.com` / `password`).
- **Showcase**: 
  - The Recruiter Dashboard.
  - Navigate to **Job Postings** and create a new job (e.g., "Senior React Developer").
  - Go to the **External Hiring Tab** to demonstrate how recruiters can generate shareable public application links for sourcing outside the platform.

### Phase 3: The Candidate Experience
- **Action**: Open an incognito window. Register a new Candidate account (or log in as an existing demo candidate).
- **Showcase**:
  - The Candidate Portal.
  - Navigate to **Profile Settings**. Demonstrate the profile management UI.
  - Upload a Resume PDF. *Crucial Point*: Explain that the backend is currently hitting the Gemini API, extracting raw text, and intelligently converting it into structured JSON (skills, experience, education) in real-time.
  - Navigate to **Jobs**, find the job created in Phase 2, and click **Apply**.

### Phase 4: The AI Evaluation Engine (The "Wow" Moment)
- **Action**: Return to the Recruiter window. Open the Job Details for the recently created job.
- **Showcase**:
  - Show the applicant list. The newly applied candidate will be visible.
  - Highlight the **AI Match Score** (e.g., 85%).
  - Click to view the Candidate Application details. Show the *AI Rationale* block, explaining exactly *why* the score was given (what skills matched, what was missing).
  - Use the action buttons to change the candidate status from "Applied" to "Shortlisted".

### Phase 5: The Admin Overview
- **Action**: Log out of the recruiter account and log in as the System Administrator (`admin@example.com` / `password`).
- **Showcase**:
  - The Admin Dashboard. Point out the real-time donut charts and system-wide metrics.
  - Demonstrate the actionable summary cards. Click on **Shortlisted Resumes**.
  - Show how the system navigates directly to the `Applications Tracking` page, pre-filtered to "Shortlisted", dynamically updating the page title and generating the "Company Name" context from the underlying user list. 
  - Point out the advanced multi-filter grid, emphasizing usability at scale and how combinations of filters work instantly on the frontend.

## 3. Anticipated Questions & Answers
- **"How does the AI prevent hallucination?"**
  - *Answer*: The prompt sent to Gemini is highly constrained. We ask for a strict JSON schema and provide the exact resume text and exact job description as the only context bounds.
- **"What happens if the AI API is down?"**
  - *Answer*: The system gracefully degrades. Applications are still recorded with an 'unevaluated' status, and recruiters can manually review or trigger a re-evaluation later.
